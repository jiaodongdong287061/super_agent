# DOTA2 7.41d 主流英雄图鉴

1. 一号位 Carry（后期核心）
2. 二号位 Mid（中单节奏）

# 一、一号位 Carry（1号位，优先占资源，后期接管比赛）
## 1. 幽鬼 Spectre
**定位**：阵地后期大核、团战切入、全图支援
技能简介
1. 幽鬼之刃：直线伤害+减速，获得穿越地形移动能力
2. 荒芜：目标周围无友军时，普攻附加纯粹伤害
3. 折射：被动分摊伤害，反弹伤害给周边敌人
4. 鬼影重重：全图生成幻象突袭任意敌方英雄，支援、收割、逼团

✅ 克制：无逃生脆皮法师、单核阵容、抱团阵地阵容
❌ 被克制：美杜莎、幻影长矛手（幻象难以清理）、末日使者（大招禁用技能物品）

## 2. 幻影刺客 Phantom Assassin（PA）
**定位**：物理爆发刺客核心
技能简介
1. 窒碍短匕：远程消耗、减速，可触发暴击
2. 魅影无形：隐身，脱离敌方视野获得高额闪避
3. 飘忽不定：常驻普攻闪避
4. 恩赐解脱：普攻概率巨额暴击

✅ 克制：低护甲脆皮、血量薄弱法系英雄
❌ 被克制：美杜莎（魔法盾抵抗秒杀）、刃甲英雄、末日使者、大量幻象英雄

## 3. 主宰 Juggernaut
**定位**：持续物理输出，自带短期技能免疫
技能简介
1. 剑刃风暴：自身技能免疫，持续AOE物理伤害
2. 治疗守卫：范围持续群体回血
3. 剑舞：普攻概率暴击
4. 无敌斩：连续无敌普攻，期间无法被选中

✅ 克制：缺少硬控制阵容、持续治疗英雄（全能骑士）
❌ 被克制：束缚型强控（暗影萨满、祸乱之源）、永恒之盘、强驱散英雄

## 4. 斯拉克 Slark（小鱼人）
**定位**：机动拉扯核心、属性窃取、持续追击
技能简介
1. 突袭：跳跃束缚敌方单体
2. 能量转移：普攻偷取敌人属性、永久叠加
3. 暗影之舞：隐身、高额生命恢复、解除负面状态
4. 深海护佑：魔晶获得护盾与解控

✅ 克制：缺少持续显隐、缺少长时间控制的脆皮英雄
❌ 被克制：持续真眼、沉默术士、末日、高额爆发瞬间秒杀

## 5. 美杜莎 Medusa（一姐）
**定位**：后期阵地永动机核心，团战前排输出
技能简介
1. 分裂箭：普攻同时攻击多个目标
2. 秘术异蛇：弹跳魔法伤害，返还魔法值
3. 魔法盾：消耗魔法承受伤害，极强坦度
4. 石化凝视：范围内敌人减速、石化，面向自身受到更强控制

✅ 克制：物理爆发刺客、近战冲脸阵容、单体秒杀英雄
❌ 被克制：高魔法爆发、无视魔免长时间控制、散失之刃英雄

## 6. 噬魂鬼 Lifestealer（小狗）
**定位**：单体攻坚核心，克制肉盾英雄
技能简介
1. 狂暴：魔法免疫、攻速加成
2. 盛宴：普攻按最大生命值吸血
3. 撕裂伤口：持续加深目标受到伤害
4. 感染：钻进友军/小兵体内，跟随移动，爆发现身

✅ 克制：高血量肉盾英雄、阵地前排
❌ 被克制：幻影长矛手等幻象体系、长时间禁锢控制

## 7. 幻影长矛手 Phantom Lancer（猴子）
**定位**：幻象推进核心，团战混乱输出
技能简介
1. 灵魂之矛：伤害+减速，生成幻象
2. 神出鬼没：隐身+幻象
3. 并列：普攻概率生成攻击幻象
4. 幻化之锋：幻象承受伤害降低

✅ 克制：缺少AOE清幻象能力的物理核心
❌ 被克制：撼地神牛、谜团、兽王拥有大范围清幻象技能

## 8. 敌法师 Anti-Mage
**定位**：机动刷钱核，法系克星
技能简介
1. 法力损毁：攻击燃烧魔法值，造成魔法值百分比伤害
2. 闪烁：短距离位移逃生/切入
3. 法术护盾：高额魔法抗性
4. 法力虚空：根据目标缺失魔法造成巨额伤害+眩晕

✅ 克制：高蓝耗法系英雄、依赖技能输出阵容
❌ 被克制：长时间禁锢控制、高额瞬间物理爆发

# 二、二号位 Mid（中单，节奏带动者）
## 1. 影魔 Shadow Fiend
**定位**：中路爆发，推进+团战AOE
技能简介
1. 影压：三段远近不同距离魔法伤害
2. 支配死灵：击杀单位永久叠加攻击力
3. 魔王降临：降低周围敌人护甲
4. 魂之挽歌：死亡时大范围AOE伤害+减速

✅ 克制：对线近战弱势英雄、抱团推进阵容
❌ 被克制：高机动游走英雄、强击杀型中单（火猫、蓝猫）

## 2. 风暴之灵 Storm Spirit（蓝猫）
**定位**：全图机动先手、持续追击
技能简介
1. 残影：范围伤害
2. 电子涡流：单体牵引控制
3. 超负荷：技能后普攻附加额外伤害
4. 球状闪电：消耗魔法全图高速飞行

✅ 克制：缺少逃生、落单脆皮英雄
❌ 被克制：沉默、高额魔法爆发、限制机动英雄（毒狗）

## 3. 灰烬之灵 Ember Spirit（火猫）
**定位**：灵活切入，持续拉扯，边线牵制
技能简介
1. 无影拳：随机范围普攻
2. 火焰枷锁：持续禁锢单体
3. 炎阳索：范围持续灼烧
4. 残焰：储存残影，自由传送

✅ 克制：缺少范围控制、单体输出英雄
❌ 被克制：沉默术士、末日使者、大范围强控

## 4. 宙斯 Zeus
**定位**：全图魔法爆发，支援型中单
技能简介
1. 弧形闪电：弹跳伤害
2. 雷击：单体高额伤害+显隐
3. 静电场：目标血量越低受到额外伤害
4. 雷神之怒：全图打击所有敌方英雄，显隐

✅ 克制：隐身英雄、残血逃跑单位、低魔抗脆皮
❌ 被克制：魔坦英雄、BKB物理核心

## 5. 祈求者 Invoker（卡尔）
**定位**：多技能多变节奏，上限极高
技能简介：冰、雷、火三元素组合10个技能；具备控制、爆发、推进、逃生能力

✅ 克制：阵容缺少驱散、缺少打断
❌ 被克制：持续沉默、强突进近身秒杀

## 6. 变体精灵 Morphling（水人）
**定位**：灵活转属性，收割拉扯中单核
技能简介
1. 波浪形态：位移+AOE伤害
2. 变体打击：普攻减速
3. 属性转换：力量/敏捷自由切换
4. 复制：复制敌方幻象

✅ 克制：缺少持续控制，单体输出英雄
❌ 被克制：长时间禁锢、散失之刃

# 三、三号位 Offlane（劣势路，前排控制/承伤）
## 1. 马尔斯 Mars
**定位**：阵地团战先手、前排承伤
技能简介
1. 神之矛：穿刺禁锢敌方
2. 护身甲盾：前方减伤护盾
3. 战吼：友军护甲加成
4. 竞技场：创造封闭战场，阻挡敌人穿越

✅ 克制：依赖位移、持续拉扯的英雄
❌ 被克制：无视地形位移、远程消耗阵容

## 2. 斧王 Axe
**定位**：前排强开、持续仇恨承伤
技能简介
1. 狂战士之吼：强制敌人攻击自身
2. 反击螺旋：受到攻击触发范围伤害
3. 战斗饥渴：持续掉血、减速
4. 淘汰之刃：斩杀低血量单位，斩杀成功刷新冷却

✅ 克制：近战扎堆阵容、持续普攻英雄
❌ 被克制：远程消耗、高额魔法爆发

## 3. 潮汐猎人 Tidehunter
**定位**：反手/先手大范围团控，肉盾
技能简介
1. 巨浪：减速+减甲
2. 海妖外壳：伤害格挡，积累伤害触发强驱散
3. 锚击：范围伤害、降低敌方攻击力
4. 毁灭：超大范围眩晕

✅ 克制：抱团突进近战阵容
❌ 被克制：强驱散、分散拉扯阵容

## 4. 兽王 Beastmaster
**定位**：推进、视野、召唤物清幻象
技能简介
1. 野性之斧：直线伤害
2. 野性呼唤：召唤野猪、战鹰获取视野
3. 兽性之心：友军攻速加成
4. 原始咆哮：单体远距离长时间眩晕

✅ 克制：幻象体系、缺少视野的阵容
❌ 被克制：召唤物清理、远程风筝

## 5. 钢背兽 Bristleback
**定位**：持续承伤，后背减伤阵地前排
技能简介
1. 粘稠鼻液：减速、减甲
2. 钢毛后背：背面、侧面受到伤害大幅降低
3. 刺针扫射：持续自动范围伤害
4. 战意：持续叠加攻击力、移速

✅ 克制：近战持续普攻阵容
❌ 被克制：多角度打击、纯粹伤害、高爆发秒杀

## 6. 谜团 Enigma
**定位**：召唤推进、最强大范围团控
技能简介
1. 憎恶：持续伤害眩晕
2. 转化：击杀小兵生成恶魔召唤物
3. 午夜凋零：范围持续纯粹伤害
4. 黑洞：持续牵引大范围控制

✅ 克制：扎堆抱团、幻象大军
❌ 被克制：打断技能、BKB英雄、强驱散

# 四、四号位 游走辅助（节奏、半装备输出）
## 1. 裂魂人 Spirit Breaker（白牛）
**定位**：全图游走定点冲锋抓人
技能简介
1. 暗影冲刺：远距离冲向目标，撞击眩晕
2. 巨力重击：普攻概率击退眩晕
3. 威吓：移速、攻速光环
4. 幽冥一击：远程突进单体伤害

✅ 克制：线上落单脆皮、无逃生英雄
❌ 被克制：持续显隐、控制打断、高机动性英雄

## 2. 米拉娜 Mirana（白虎）
**定位**：游走、偷袭、隐身团战
技能简介
1. 群星风暴：范围伤害
2. 月神之箭：远距离长眩晕（距离越远控制越久）
3. 跳跃：位移、攻速加成
4. 月之暗面：全队隐身偷袭

✅ 克制：缺少真眼、视野差的阵容
❌ 被克制：持续真实视野、大范围AOE

## 3. 撼地神牛 Earthshaker
**定位**：群体控制，幻象体系杀手
技能简介
1. 沟壑：地形隔断+眩晕
2. 强化图腾：下次普攻巨额伤害
3. 回音击：产生冲击波，单位越多伤害越高
4. 余震：释放技能触发周围眩晕

✅ 克制：幻象、扎堆密集单位
❌ 被克制：分散拉扯、BKB先手冲脸

## 4. 莱恩 Lion
**定位**：游走爆发、双控制
技能简介
1. 穿刺：范围眩晕
2. 妖术：单体变羊禁锢
3. 法力汲取：持续吸取魔法
4. 死亡之指：单体高额魔法爆发

✅ 克制：脆皮落单核心
❌ 被克制：BKB、魔法免疫英雄

## 5. 拉比克 Rubick（大魔导师）
**定位**：战术多变，窃取敌方关键技能
技能简介
1. 隔空取物：举起单位滞空控制
2. 弱化能流：链式伤害减攻
3. 技能窃取：盗取敌方最后释放技能

✅ 克制：拥有强力大招/关键技能的阵容
❌ 被克制：沉默、瞬间爆发秒杀

# 五、五号位 纯功能辅助（保线、视野、团队功能）
## 1. 水晶室女 Crystal Maiden（冰女）
**定位**：光环回蓝、团控、对线消耗
技能简介
1. 冰霜新星：范围减速伤害
2. 冰封禁制：单体持续禁锢
3. 辉煌光环：全队持续魔法恢复
4. 极寒领域：大范围持续减速+伤害

✅ 克制：依赖频繁放技能的法系阵容
❌ 被克制：突进型刺客，极易被先手秒杀

## 2. 巫医 Witch Doctor
**定位**：持续治疗、诅咒伤害、团战大招输出
技能简介
1. 麻痹药剂：弹跳眩晕
2. 诅咒：持续百分比伤害
3. 死亡守卫：持续单体治疗
4. 死亡守卫：持续远程机枪输出

✅ 克制：缺少打断、抱团阵地敌人
❌ 被克制：快速打断、近身秒杀

## 3. 暗影萨满 Shadow Shaman（小Y）
**定位**：多控制、推进、长时间禁锢
技能简介
1. 苍穹震击：链式伤害
2. 妖术：变羊禁锢
3. 枷锁：持续单体束缚
4. 群蛇守卫：大量蛇棒推进输出

✅ 克制：缺少清召唤物、缺少打断核心
❌ 被克制：大范围AOE清理蛇棒

## 4. 全能骑士 Omniknight
**定位**：团队保护、物理免疫、治疗
技能简介
1. 洗礼：治疗+伤害
2. 驱逐：单体魔法免疫
3. 退化光环：降低周围敌人移速攻速
4. 守护天使：全队物理免疫

✅ 克制：纯物理输出阵容
❌ 被克制：纯粹伤害、魔法爆发、驱散

## 5. 树精卫士 Treant Protector
**定位**：视野侦查、先手控制、大树隐身游走
技能简介
1. 活体护甲：友军护甲+持续回血
2. 丛林之眼：种子侦查视野
3. 寄生种子：持续吸血减速
4. 疯狂生长：大范围束缚控制

✅ 克制：缺少视野、落单带线英雄
❌ 被克制：大范围AOE、显隐道具

## 6. 寒冬飞龙 Winter Wyvern
**定位**：反手大招战略型辅助
技能简介
1. 严寒灼烧：持续远程消耗
2. 极寒之触：强化队友远程攻击
3. 古龙之赐：自身保命护盾
4. 寒冬诅咒：强制目标被队友集火，受到伤害加深

✅ 克制：扎堆近战核心、物理抱团阵容
❌ 被克制：分散拉扯、瞬间秒杀

# 补充通用克制机制（BP选英雄参考）
1. 幻象体系克星：神牛、谜团、兽王、大电锤、辉耀
2. 物理核心克星：全能骑士、毒龙、美杜莎、天堂之戟
3. 法系英雄克星：敌法师、林肯法球、挑战头巾
4. 隐身英雄克星：真视宝石、岗哨守卫、雷击、显隐技能
5. 持续治疗克星：厄运之源、否决挂饰、寒冬飞龙大招
