# 机票折扣计算规则

## ⚠️ 强制要求：必须联网查询全价

**机票全价必须联网搜索获取，不能使用参考表或估算值！**

使用 `web_search` 搜索：`{出发城市}到{目的地城市} 经济舱全价机票`

---

## 核心原则

**剔除机建费和燃油费后，以最贵全价机票为基准计算折扣**

---

## 计算步骤

### 步骤1：获取票面价

```
票面价 = 实际支付金额 - 机场建设费 - 燃油附加费
```

**费用标准参考：**
- 机场建设费：通常为 50 元
- 燃油附加费：根据航程和油价浮动，常见值为 0/10/20/30/50 元

### 步骤2：联网搜索全价基准

**必须联网搜索该航线所有航司的经济舱全价，取最高值：**

```
搜索关键词：{出发城市}到{目的地城市} 经济舱全价机票
```

从搜索结果中：
1. 提取各航司的经济舱全价
2. 选择**最贵**的一档作为基准

示例搜索结果：
| 航司 | 全价 | 是否基准 |
|------|------|----------|
| 国航 | 1500元 | ✓ 最贵 |
| 南航 | 1400元 | |
| 东航 | 1350元 | |

**基准全价 = 1500元**

### 步骤3：计算折扣率

```
折扣率 = 票面价 / 全价基准
折扣显示 = 折扣率 × 10（保留一位小数）
```

---

## 计算示例

### 示例1：单航程

**输入：**
- 实际支付：1059.78元
- 机建费：50元
- 燃油费：10元
- 全价基准：1530元（国航）

**计算：**
```
票面价 = 1059.78 - 50 - 10 = 999.78元
折扣率 = 999.78 / 1530 = 0.6535
折扣显示 = 6.5折
```

**输出：** `1059.78元（6.5折）`

### 示例2：多航程

**输入：**
- 去程实际支付：800元，机建费50元，燃油费0元
- 返程实际支付：900元，机建费50元，燃油费10元
- 全价基准：1200元

**计算：**
```
去程票面价 = 800 - 50 - 0 = 750元
去程折扣 = 750 / 1200 = 6.3折

返程票面价 = 900 - 50 - 10 = 840元
返程折扣 = 840 / 1200 = 7.0折
```

**输出：**
```
飞机票：3月4日 南京-湛江，800元（6.3折）；3月6日 湛江-南京，900元（7.0折）；合计：1700元
```

---

## 费用标准参考

**机场建设费：** 通常为 50 元

**燃油附加费：** 根据航程和油价浮动，常见值为 0/10/20/30/50 元

> **注意：** 票据中通常会注明机建费和燃油费金额，以实际票据为准。
