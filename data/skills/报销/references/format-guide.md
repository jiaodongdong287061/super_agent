# 输出格式规范

## 输入数据处理

### 数据清洗规则

在提取费用信息前，需对输入数据进行清洗：

| 清洗项 | 规则 | 示例 |
|--------|------|------|
| 数字编号 | 移除开头的数字编号 | `020219_维修费` → `维修费` |
| 下划线 | 移除下划线分隔符 | `维修费_北京` → `维修费北京`（或保留语义） |
| 括号内容 | 移除括号及其内容 | `维修费（北京项目）` → `维修费` |

### 组合清洗示例

```
输入: 020219_维修费（北京项目）
步骤: 移除编号 → 移除下划线 → 移除括号内容
输出: 维修费
```

```
输入: 020220_手续费
步骤: 移除编号 → 移除下划线
输出: 手续费
```

## 输出格式

### 标准格式

```
费用类别：日期 行程，金额；日期 行程，金额；合计：总金额
```

### 费用类别说明

| 类别 | 格式 | 示例 |
|------|------|------|
| 打车费 | 日期 起点-终点，金额 | `打车费：3月4日 湛江机场-酒店，109元；合计：109元` |
| 飞机票 | 日期 行程，金额（折扣）；合计：总金额 | `飞机票：3月4日 南京-湛江，1059.78元（6.9折）；合计：1059.78元` |
| 住宿费 | 日期范围 地点，金额 | `住宿费：3月4日-6日 湛江，677.92元；合计：677.92元` |
| 出差补助 | 日期范围 城市（天数），标准，合计 | `出差补助：3月4日-6日 湛江（3天），60元/天，合计：180元` |
| 其他 | 日期 项目，金额 | `其他：3月5日 餐饮，50元；合计：50元` |

### 总计格式

```
---

总计报销金额：XXX.X元
```

---

## 飞机票折扣显示

飞机票费用需显示折扣率，格式为：`金额（X.X折）`

示例：
- `1059.78元（6.9折）`
- `800元（5.3折）`

---

## 完整输出示例

```
打车费：3月4日 湛江机场-酒店，109元；3月5日 环保局-餐厅，13.7元；合计：122.7元

飞机票：3月4日 南京-湛江，1059.78元（6.9折）；合计：1059.78元

住宿费：3月4日-6日 湛江，677.92元；合计：677.92元

出差补助：3月4日-6日 湛江（3天），60元/天，合计：180元

---

总计报销金额：2040.4元
```

## 出差补助标准

| 城市 | 每日补助 |
|------|----------|
| 广州、深圳、上海 | 80元/天 |
| 其他城市 | 60元/天 |

**计算方式：**
- 天数 = 截止日期 - 开始日期 + 1
- 补助金额 = 天数 × 日补助标准
