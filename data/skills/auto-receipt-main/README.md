# AutoReceipt

> Claude Code Agent Skill - 自动化差旅报销处理

## 功能说明

AutoReceipt 帮助你：
1. **按照公司标准重命名所有发票和行程单**
2. **生成可以一键导入报销系统的 Excel 报销明细**

## 使用流程

```
┌─────────────────┐
│ 1. 准备发票 PDF  │  将所有差旅发票放入一个文件夹
└────────┬────────┘
         ↓
┌─────────────────┐
│ 2. 运行 Skill   │  在 Claude Code 中启动 AutoReceipt
└────────┬────────┘
         ↓
┌─────────────────┐
│ 3. 填写基本信息  │  出发城市、到达城市等
└────────┬────────┘
         ↓
┌─────────────────┐
│ 4. 获取输出     │  重命名后的发票 + 报销明细 Excel
└────────┬────────┘
         ↓
┌─────────────────┐
│ 5. 提交报销     │  上传发票附件 → 一键导入报销明细
└─────────────────┘
```

## 系统要求

| 依赖 | 说明 |
|-----|------|
| **Claude Code** | Anthropic 官方 CLI 工具 |
| **视觉识别大模型** | 推荐使用 GLM-4.6V-Flash（免费），也可使用其他视觉模型 |

## 获取视觉模型 API Key

**推荐：GLM-4.6V-Flash（免费）**

1. 访问 [智谱开放平台](https://bigmodel.cn/)
2. 注册账号
3. 进入控制台创建 API Key
4. **GLM-4.6V-Flash 免费**，无需充值

> 如有自己的视觉识别大模型，可在配置中自行指定。

## 快速开始

详细安装指南请参阅 **[SETUP_GUIDE.md](./SETUP_GUIDE.md)**

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 GLM API Key（首次运行时自动引导）
```

## 支持的费用类型

| 类型 | 说明 |
|-----|------|
| 机票 | 含民航发展基金、保险费自动合并 |
| 火车票 | 含退改签费自动合并 |
| 打车费 | 含高速通行费自动合并，支持滴滴/出租车 |
| 住宿费 | 自动识别住宿天数 |
| 餐补费 | 按城市标准自动计算 |
